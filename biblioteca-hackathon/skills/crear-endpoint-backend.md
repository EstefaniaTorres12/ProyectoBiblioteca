# Skill: crear endpoint backend

## Objetivo
Crear un endpoint REST en Express respetando arquitectura por capas.

## Pasos
1. Crear o actualizar validator Zod.
2. Crear método en repository si requiere DB.
3. Crear método en service con regla de negocio.
4. Crear método en controller.
5. Registrar ruta en `routes`.
6. Agregar prueba.
7. Actualizar README si cambia uso externo.

## Resultado esperado
Endpoint funcional, validado y testeado.
