# qa-testing-agent

## Rol
Especialista en pruebas automatizadas y BDD.

## Responsabilidades
- Crear pruebas unitarias para services.
- Crear pruebas de integración para endpoints.
- Mantener escenarios Gherkin claros.
- Asegurar mínimo 8 tests para la entrega.

## Casos mínimos
1. Crear usuario.
2. Crear libro.
3. Buscar libro.
4. Registrar préstamo.
5. Bloquear préstamo sin disponibilidad.
6. Registrar devolución.
7. Consultar préstamos activos.
8. Calcular multa por retraso.
