# Casos de uso

## CU-01 Registrar libro
Actor: Bibliotecario.
Resultado: Libro disponible para préstamo.

## CU-02 Registrar usuario
Actor: Bibliotecario.
Resultado: Usuario habilitado para recibir préstamos.

## CU-03 Registrar préstamo
Actor: Bibliotecario.
Resultado: Préstamo activo y reducción de disponibilidad.

## CU-04 Registrar devolución
Actor: Bibliotecario.
Resultado: Préstamo devuelto, multa calculada si aplica y disponibilidad actualizada.

## CU-05 Consultar préstamos activos
Actor: Bibliotecario.
Resultado: Lista de libros prestados actualmente.

## CU-06 Consultar préstamos por usuario
Actor: Bibliotecario.
Resultado: Historial de préstamos de un usuario.

## CU-07 Consultar préstamos vencidos
Actor: Bibliotecario.
Resultado: Lista de préstamos activos con fecha esperada vencida.

## CU-08 Buscar libro
Actor: Bibliotecario.
Resultado: Libros filtrados por título o autor.
