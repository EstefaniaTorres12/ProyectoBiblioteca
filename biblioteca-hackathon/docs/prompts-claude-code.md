# Prompts sugeridos para Claude Code

## Crear funcionalidad backend

```text
Usa el backend-node-agent y el skill crear-endpoint-backend. Implementa el endpoint para [describir funcionalidad]. Respeta la arquitectura por capas y agrega pruebas.
```

## Crear pantalla frontend

```text
Usa el frontend-react-agent y el skill crear-componente-react. Crea la pantalla para [describir pantalla]. Consume la API desde un archivo .api.ts y usa Material UI.
```

## Revisar tests

```text
Usa el qa-testing-agent. Revisa que existan mínimo 8 tests automatizados relacionados con los requisitos core y adicionales de la hackathon. Agrega los faltantes sin modificar comportamiento innecesario.
```

## Revisar seguridad

```text
Usa el security-agent. Revisa validaciones, manejo de errores, secretos, CORS y Helmet. Propón cambios mínimos y aplícalos si son seguros.
```
