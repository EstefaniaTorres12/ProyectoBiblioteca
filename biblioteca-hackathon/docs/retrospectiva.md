# Retrospectiva sugerida

## Qué salió bien
- Se dividió el sistema en frontend, backend y base de datos.
- Se priorizaron los requisitos core.
- Se agregaron pruebas automatizadas mínimas.

## Qué se podría mejorar
- Agregar autenticación real por roles.
- Mejorar formularios y validaciones del frontend.
- Agregar pruebas end-to-end.
- Implementar notificaciones automáticas para libros vencidos.

## Qué cambiaríamos
- Definir reglas de negocio con más detalle desde el inicio.
- Crear datos de prueba antes de iniciar la implementación.
